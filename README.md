# Naphium Digital Portfolio

Build a fully responsive, ultra-minimalist, modern personal portfolio, social handle hub, and developer dashboard web application for Md. Nafim Muttaki (username: "naphium", location: "Rajshahi", Bangladesh). The site should have a sophisticated, non-cringe, aesthetic combining a deep black background with a cool slate-blue, steel-blue, white, and black color palette. the site title is Md. Nafim Muttaki Portfolio

### 1. Visual & Design System
- **Color Palette:**
  - Base Background: Pure Deep Black (#000000)
  - Card Surfaces / Containers: Deep Slate Blue-Charcoal (#1B3A57 and #112233) with crisp White (#FFFFFF) text containers
  - Typography & Headlines: High-contrast Pure White (#FFFFFF) and Ice Blue (#A4C8E1) for subtext
  - Accents & Active Highlights: Steel Blue (#4A6E8D) and Ice Blue (#A4C8E1) with sharp 1px borders
- **Background Effect:**
  - Animated canvas background featuring smooth elevation topographic contour lines and a tactical grid matrix with crosshairs and coordinate markers (e.g., 24°22'26"N 88°36'04"E).
- **Typography:**
  - Clean serif headlines (Playfair Display / Georgia) paired with monospace/sans-serif details (JetBrains Mono) for code, timestamps, and metadata.

### 2. Core Header & Hero Section
- Centered circular avatar with glowing status badge and live local time/clock for Rajshahi.
- Name and tagline: "Md. Nafim Muttaki (n a f i m)" with location metadata and bio.
- Interactive Discord-style Rich Presence Widget: Live status indicator ("naphium ⚡ DEV"), activity switcher (Coding, Listening, Idle), and live elapsed time counter.
- Interactive Banner Customizer: Allows switching banner modes (Tactical Grid, Contour Topography, Cosmic Gradient, Minimalist Slate) with localStorage persistence.

### 3. Fully Visible Navigation Bar
- A clean, responsive grid of interactive tab buttons so that all navigation options are visible simultaneously without scrolling issues.

### 4. Comprehensive Tabbed Content Sections (11 Detailed Tabs)
Each tab must be packed with rich, detailed content and sub-sections:
1. **About:** Overview of background as an HSC Science student in Rajshahi, engineering philosophy, workstation hardware specs, and academic metrics.
2. **Links:** Categorized Developer, Social, and Gaming handles (GitHub, Discord, Instagram, Spotify, Twitch, Facebook, Email, Roblox, Pinterest) with one-click copy toast notifications and live view counter badges.
3. **Projects:** Detailed cards for Web Apps, Custom Client Tools (Naphium Chess, Stockfish Wasm), ESP8266 Firmware, and High School Festival branding ('নিরুদ্বেগ-২৬').
4. **Skills:** Progress bars and tech stack badges covering Frontend Web Engineering, Embedded Firmware, Cloud/Serverless Architecture, and Graphic Design.
5. **Timeline:** Chronological milestone entries spanning from 2024 to 2026.
6. **Goals:** Academic HSC 2028 targets, Wasm performance objectives, and open-source benchmarks.
7. **Setup & Gear:** Ryzen 5 3400G rig specs, TP-Link network registry tweaks, and VS Code/Fabric Sodium setup.
8. **Album:** Interactive vector artwork and photo gallery featuring modal lightbox zoom.
9. **Guestbook:** Fully functional local storage message wall allowing visitors to post notes with custom names and roles.
10. **Audio Lounge:** Persistent bottom Web Audio API synthesizer music player with track info, progress scrubber, volume controls, play/pause, and animated equalizer bars.
11. **FAQ:** Accordion cards addressing hosting philosophy, Rajshahi context, and project collaboration.

### 5. Technical Requirements
- Single-file standalone HTML (HTML5, Tailwind CSS or clean CSS variables, and Vanilla JavaScript).
- Zero external broken images or heavy CDN bloat; use inline SVGs and CSS shapes for icons and visuals.
- Fully responsive layout optimized for mobile, tablet, and desktop viewports.
